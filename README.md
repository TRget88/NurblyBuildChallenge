# NurblyBuildChallenge
Landing page for the Nurbly Build Challenge.

To publish, open Settings, then Pages, and set it to deploy from the `main` branch, `/ (root)` folder.
To change the Register, rules, Discord and contact links, edit the constants in the `<script>` block at the top of `index.html`. Leave `DISCORD_URL` empty to hide the Discord mention.
