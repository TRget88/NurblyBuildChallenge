# NurblyBuildChallenge
Landing page for the Nurbly Build Challenge.

To publish, open Settings, then Pages, and set it to deploy from the `main` branch, `/ (root)` folder.
To change the Register, rules, Discord and contact links, edit the constants at the top of `site.js`. Both pages use them. Leave `DISCORD_URL` empty to hide the Discord mention.

The official rules live in `rules.html`. When the rules change, update its "Last updated" date and check that the landing page's prizes, dates, judging and rules summary still match.
